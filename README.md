# calculator-project

This is a simple calculator that I made using HTML, CSS and JavaScript.

I made this project while practicing JavaScript and DOM manipulation. It can perform basic calculations and has buttons for AC, cut, percentage, decimal values and other basic operations.

The calculator has a simple blue and white design and is responsive, so it can be used on both laptop and mobile screens.

# Technologies Used

* HTML
* CSS
* JavaScript

This was one of my practice projects to improve my understanding of JavaScript and how it works with HTML elements.
